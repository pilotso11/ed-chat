## Short description

An AI chat overlay for Elite Dangerous, for Claude Code or OpenAI's Codex.

## Description

ED Chat is a small chat window on top of Elite Dangerous. Press a hotkey, ask a
question, press Enter, and keep flying. The reply shows in a corner of the screen.
Star system and station names in the reply become chips that you copy with one key,
ready to paste into the galaxy map.

ED Chat drives an assistant that you install and log in to yourself: Claude Code
(Anthropic) or the Codex CLI (OpenAI). Type /claude or /codex to switch. Your
messages go only to the assistant you chose, under that company's terms.

With ed-mcp, the assistant reads your game journal and looks up routes, engineers,
materials, trade and stations. Set ed-mcp up once, in either assistant.

An activity panel shows what you are doing: the exobiology on a planet, the bodies
in a system, your massacre missions or your route.

Requirements: Windows 10 or 11, Elite Dangerous in Borderless or Windowed mode, and
Claude Code or the Codex CLI installed and logged in.

## What's new in this version

You can now use OpenAI's Codex instead of Claude Code. Type /codex or /claude in the
chat, or use the tray menu's Assistant item. Each assistant keeps its own
conversation, and ed-mcp is set up once for both.
